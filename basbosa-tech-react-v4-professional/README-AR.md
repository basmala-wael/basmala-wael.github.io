# Basbosa Tech — نسخة React

دي نفس بسبوسة تيك بالظبط (نفس الشكل والألوان والصور والمميزات) متعاد بناؤها بـReact. النسخة العادية بتاعتك (HTML + CSS + JavaScript) موجودة زي ما هي، دي نسخة تعليمية جنبها عشان تشوفي نفس الموقع مكتوب بالطريقتين. التحويل اتعمل بالكامل كمساعدة تعليمية — مش شغل إنتِ كاتباه.

## تشوفيها إزاي (من غير أي تثبيت)
افتحي فولدر `dist` ودوسي دبل-كليك على `index.html` — بتشتغل في المتصفح على طول زي النسخة العادية. خلي فولدر `images` جنب الملف.

## تشتغلي عليها إزاي (لما تحبي تتعلمي)
1. ثبّتي Node.js من nodejs.org (نسخة LTS).
2. في التيرمنال جوه الفولدر ده: `npm install` (أول مرة بس).
3. `npm run dev` وافتحي اللينك اللي هيظهر (غالبًا localhost:5173).
4. أي تعديل في ملفات `src` بيظهر في المتصفح فورًا.
5. `npm run build` بيطلع نسخة معاينة جديدة في `dist`.

## الخريطة (src)
- `data/products.js` — كتالوج المنتجات (نفس PRODUCTS بتاع النسخة العادية، مصدر واحد).
- `context/CartContext.jsx` — السلة: كانت متغير عام، بقت Context. أي مكوّن يقدر يقراها أو يضيف لها، والشاشة بتتحدث لوحدها.
- `context/SearchContext.jsx` — كلمة البحث بين الهيدر والشبكات.
- `components/` — Header وFooter وProductCard وProductGrid. الكارت بيتكتب مرة وبيستخدم لكل منتج.
- `pages/` — Home وCategory وProduct وCart وCheckout وContact وCategories.

## إيه اللي اتغيّر مقارنة بالنسخة العادية؟
- 9 ملفات HTML بقوا مكوّنات React وصفحات، والتنقل بـReact Router (لينكات زي ‎/product/iphone-14 بدل ‎Product.html?id=iphone-14).
- كل `onclick` و`classList.toggle` و`document.querySelector` بقوا State (`useState`) وأحداث React (`onClick`).
- التايمر بتاع السلايدر بقى `useEffect`، والعدّادات بتتحدث تلقائيًا لأن React بترسم من جديد لما الـState يتغير.
- السلة لسه متخزنة في localStorage بنفس المفتاح، فسلتك القديمة بتفضل موجودة.
- نفس ملف CSS حرفيًا (src/styles.css)، عشان الشكل يفضل هو هو.

## الجديد في النسخة دي (v4)
- صفحات السلة والدفع والأقسام اتصممت من جديد بشكل احترافي: حالة سلة فاضية واضحة، ملخص طلب جنب فورم الدفع، وصفحة نجاح فيها زرار رجوع.
- ترتيب المنتجات في صفحات الأقسام: مميز / السعر من الأقل / من الأعلى / أبجدي.
- كل منتج بقى ليه وصف ومواصفات مختصرة في صفحة التفاصيل (مواصفات معلنة من الشركات المصنعة).
- صور المنتجات بستايل موحد، والنسخ الأصلية محفوظة في `original-images-backup/` للمقارنة.

## حدودها
زي النسخة العادية: متجر تجريبي، مفيش طلبات أو دفع حقيقي، وفورم التواصل مكتوب عليه إنه تجريبي. مفيش Backend ولا استضافة.
